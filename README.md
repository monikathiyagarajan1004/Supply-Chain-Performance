Supply Chain Analytics

📌 Project Overview

This project analyzes supply chain data to evaluate sales, inventory, demand, order fulfillment, and overall supply chain performance**. Excel, SQL, and Power BI were used for data preparation, analysis, KPI calculation, and interactive dashboard development.

🎯 Objectives

* Analyze sales and order performance
* Monitor inventory levels and reorder requirements
* Compare actual demand with forecast demand
* Evaluate order fulfillment and delivery performance
* Track key supply chain KPIs
* Identify products requiring inventory attention

🛠️ Tools Used

* **Microsoft Excel** – Data cleaning, preparation, and analysis
* **SQL** – Data querying, aggregation, and analysis
* **Power BI** – Data modeling, DAX, KPI analysis, and interactive dashboard

📊 Key Analysis

* Total Sales
* On-Time Delivery %
* Fill Rate %
* Reorder Ratio
* Items Requiring Reorder
* Stock on Hand vs. Reorder Level
* Actual vs. Forecast Demand
* Order and Shipment Performance

📈 Dashboard

An interactive Power BI dashboard was created to monitor supply chain performance through key KPIs, inventory analysis, demand comparison, and order fulfillment metrics.

💡 Key Insights

The analysis provides insights into sales performance, inventory availability, reorder requirements, demand patterns, and order fulfillment to support data-driven supply chain decisions.

📂 Project Files

* `Supply_Chain_Dataset.xlsx` – Dataset and Excel analysis
* `Supply_Chain_SQL.sql` – SQL queries and analysis
* `Supply_Chain_Dashboard.pbix` – Power BI dashboard
